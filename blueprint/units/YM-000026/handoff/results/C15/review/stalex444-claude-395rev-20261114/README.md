## Outcome

- **Mathematics: changes requested** ([mathematics.md](mathematics.md)). One required change, M1: the lemma is stated for every N satisfying a_N(Z_d+2) < 3a_w/8 (l.195–198), but its proof uses that a_k/a_N is an integer (l.213), which needs N ≥ k, and the mesh condition does not imply N ≥ k; when Z_d = 0 it holds at N = w + 2, which is below k whenever k > w + 2. Adding N ≥ k (or N > k, as at l.105 and in (G3)) to the quantifier closes it. Every other step of the proof is correct: the odd side q = a_w/a_N, the home cell, the site bound |u_α| ≤ q/8, the endpoint bound and the chain q/8 + Z_d + 1 < q/2 − 1 < (q−1)/2, and chamber-admissibility. Given the #393 interface, the statement with N ≥ k delivers (G4) with w_i = w clause by clause. (G4) itself is unaffected by M1: it asks only for all sufficiently large N, and the proof is complete for every N ≥ k that satisfies the mesh condition. M2 and M3 are minor.
- **Lean correspondence: changes requested, by the one change of M1** ([lean-correspondence.md](lean-correspondence.md)). The source counterpart `Next.Rank.Station.FitSky.stencils` (`Prom/Hill/Coordinates.lean:150`) states `∃ hN : k≤N`, and the lemma omits it (L5). No other mismatch was found: the fitness bound, the odd side, the home chamber, the site bound and the conclusion `Interior (T.chamber 0)` match. The explicit mesh condition has no source counterpart and is implied by the source's own sufficient condition (with Z_d the largest coordinate of a nonempty stencil); with that condition, the uniformity in the fit point and "strictly inside", the lemma says more than the source (L6, L8, L10). The probe elaborates the statements of `FitSky.stencils` and the declarations it is built from, and kernel-checks eight probe theorems restating or directly assembling release declarations; it does not formalise the lemma's explicit mesh condition. The record's pairing is correct; L13 (Minor) concerns the author record only.

The verdicts are conditional on the #393 interface (w ≤ ℓ ≤ k, the middle-cell spacing a_ℓ, and the depth of the root tests), which this review does not establish.

## Findings

Labels: Required / Should / Minor. Identifiers: M = mathematics, L = Lean correspondence, C = checked and correct, N = not checked. Line numbers are those of `trace-firesky-gallery.tex` at `29f27cdb` unless another file is named; "comparison" is `trace-rounded-comparison.tex`, "receipt" is `trace-rounded-receipt.tex`.

- **M1 (Required).** The lemma quantifies "for every $N$ with" (l.195) the mesh condition only. The proof's "Since $a_k/a_N$ is an integer" (l.213) holds only for N ≥ k, and the condition forces only N > w: block lengths are at least 3 (`common-scale-selection.tex` l.41), so it holds at N = w + r once 3^r > 8(Z_d+2)/3. For such N below k, z_c is in general not a level-N site and no insertion is supplied (the witness fields take N > k, l.105). Suggested repair: "for every $N\ge k$ with" at l.195 (or $N>k$); the lemma then applies from the larger of k and the mesh threshold, still uniform in p, the label and the fit point. In the source: L5.
- **M2 (Minor, optional).** The statement does not name the base of "the centered tiling at depth $w$" (l.201); the proof fixes it at the origin (l.212–214), which is the reading the consumer's product step needs (comparison l.236–238). The #374 endpoint record (`results/C15/endpoints/hairer-claude-374-20261114/README.md` §2) already records the source tiling as `center … 0`. Optional: "based at the origin" at l.201, or once in the #393 paragraph (l.100).
- **M3 (Minor; author record).** The record's base line (l.5) names `67de733`; the parent of `29f27cdb` is `63820370`. The intervening commit changes only `lem:ex-lattice-firesky-solves` and the #392 record, so the lemma's interface is unaffected.
